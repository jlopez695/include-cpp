# Array Contains Duplicates

In this problem, you will define `ContainsDuplicate(int array[], unsigned int array_size)`. This function must return `true` if any integer value in `array` appears at least twice; `false` if every element in `array` is distinct. Please write your declaration for this function in `solution.hpp` and then define it in `solution.cc`.

## Testing Your Code

Run `make` to build the driver, then `./main` to try it out. Run `make test` to run the grader.
