# Array Contains Duplicates

## The Files

- `solution.hpp`: The header file. Write your declaration for `ContainsDuplicate` here.
- `solution.cc`: The source file. Define `ContainsDuplicate` here.
- `driver.cc`: A driver file for you to write test statements in and observe the output. Edit it freely to try things out — it is not graded.

## The Problem

Define `ContainsDuplicate(int array[], unsigned int array_size)`. This function must return `true` if any integer value in `array` appears at least twice; `false` if every element in `array` is distinct.

Write your declaration for this function in `solution.hpp` and then define it in `solution.cc`.

## Testing Your Code

Run `make` to build the driver, then `./main` to try it out. Run `make test` to run the grader.

## Graded Files

`solution.hpp` and `solution.cc` are graded. `driver.cc` is yours to experiment with.
